## Описание
Плагин для переименования переменных в коде C. Он добавляет к именам переменных префиксы, указывающие на их тип:

- `global_` — глобальные переменные
- `param_` — параметры функций
- `static_` — статические локальные переменные
- `local_` — обычные локальные переменные

PS если переменая уже имеет преффикс, то плагин не пределает еще один (если была static_var, то так и останется)
